# Skill Authoring

Use to add or revise a skill in this ecosystem.

Start from a functional requirement, not another author's prompt text. Define
the trigger, expected inputs, bounded workflow, output contract, safety limits,
dependencies, and observable quality checks. Keep instructions specific enough
to guide behavior but short enough to load economically. Separate reusable
method from product-specific facts.

Create an English `SKILL.md`, add catalog metadata and profile membership, and
test installation and discovery. Check for overlap before creating a new name.
Record external tools and network behavior explicitly. Never remove attribution
or cosmetically rewrite restricted content to claim originality.
