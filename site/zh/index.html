第一次扫描无需 Docker。

准备并运行额外扫描

将请求复制到 AI 应用。助手会检查兼容性、指导 Docker 设置并准备镜像。无需手动选择镜像 ID 或编写命令。

当前构建方式：macOS 或 Linux 上的原生 ARM64 Docker 主机。Windows 内置检查不需要 Docker。

CEO AI / 适合你的工作

职业不同，思考方法相通。

CEO 最初用于软件开发。同样的方法也适用于需求说明、客户方案和研究问题：明确目标、讨论选择、完成工作，再检查结果。

01软件开发重写之前，先找出原因+

你的任务

“报告生成太慢了，要不要重写整个服务？”

CEO 如何帮助

检查测量数据，比较局部修复与重写的成本，并制定实施和测试计划。

可以产出什么

有测量依据的改动、测试结果，以及是否重写的决定。

02市场营销把想法变成可验证的实验+

你的任务

“我们要推出新产品，但推广预算有限。”

CEO 如何帮助

明确受众和卖点，质疑渠道假设，起草宣传文案并设计小规模实验。

可以产出什么

推广简报、文案草稿和衡量实验结果的计划。

03销售准备切合客户需求的方案+

你的任务

“帮我准备与潜在客户的会议。”

CEO 如何帮助

根据你的笔记识别客户问题、尚未回答的问题，以及方案中缺乏依据的承诺。

可以产出什么

会议议程、需求访谈问题和待审核的提案草稿。

04管理决定团队先做什么+

你的任务

“三个项目都重要，但团队只能先做一个。”

CEO 如何帮助

比较目标、工作量、依赖关系和延期成本，检查优先级，并明确什么证据会改变决定。

可以产出什么

决策说明、工作顺序和重新评估计划的条件。

05设计画界面之前，先检查需求+

你的任务

“用户在这个流程中放弃了，应该改哪里？”

CEO 如何帮助

审视已有证据，区分可用性问题与假设，并比较设计方案。

可以产出什么

修改后的需求说明、用户流程方案和可用性测试计划。

06研究判断证据真正支持什么+

你的任务

“这些资料相互矛盾，帮我理清它们。”

CEO 如何帮助

对比你提供的资料，区分结论与假设，指出证据缺口。联网研究需要浏览工具。

可以产出什么

附来源的比较、待解决的问题和下一步研究方向。

这些是使用场景示例，不是客户成功案例。结果取决于模型、你提供的材料以及应用可用的工具。CEO 不会自动获得 CRM、广告账户或设计软件的访问权限。

CEO AI / Q&A

开始前，了解这几件事。

CEO AI 正在积极开发中。我们持续测试这个协调任务的技能，并根据测试结果和反馈改进它。

查看安装帮助 ↗
会安装什么？+

一个包含 CEO、Writer 和 Security Scan 的插件。项目安装器仅提供主技能。不安装新模型、创建账户或自动注册智能体。

需要 Docker 吗？+

内置检查不需要 Docker；只有主动运行额外 Security Scan 才需要。支持的平台和设置方法见单独的 Docker 指南。

它只会赞同我吗？+

CEO 检查你提出的方案是否有助于实现目标。建议应基于证据、权威一手资料和适用的成熟实践，并明确说明缺口。决定权在你，赞同或反对都不应是自动反应。

哪些内容已经验证？+

已在 macOS 上检查插件安装、更新、卸载和技能发现。项目安装程序通过 Windows、Linux 和 macOS CI 验证。尚未验证模型调用。版本和限制见插件说明。

安装停止了怎么办？+

保留文件，让智能体说明冲突或缺少的权限。帮助文档介绍了找不到技能、更新中断以及从旧版迁移的处理方法。

AI 会出错，第二个 AI 的审查也可能出错。CEO 不会获得额外权限，也不能替代项目要求的安全审查。
