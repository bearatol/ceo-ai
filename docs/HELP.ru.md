# Помощь с установкой

[English](HELP.md) · [Русский](HELP.ru.md) · [简体中文](HELP.zh-CN.md)

Выберите подходящий случай. Проверки можно поручить агенту, вводить команды
в терминале самостоятельно не нужно.

## Навык не появился

Начните новый чат в том же проекте, куда установили CEO AI. В Codex используйте
`$ceo-ai`, в Claude Code и Cursor: `/ceo-ai`. Если навык всё ещё не появился,
отправьте агенту:

> Проверь установку CEO AI в этом проекте по INSTALL.md из
> https://github.com/bearatol/ceo-ai. Определи текущее приложение, проверь папку
> навыка и его файлы. Отдельно выясни, может ли приложение загрузить ceo-ai.
> Сохрани существующие файлы и разрешения.

Установщик проверяет файлы. Загрузка навыка проверяется отдельно, а разные версии
приложений могут вести себя по-разному. Если приложение не умеет запускать других
ИИ-помощников, CEO всё равно может обсуждать задачу, но должен сообщить, какие
независимые проверки ему недоступны.

## Установка остановилась или запрашивает доступ

Попросите агента объяснить, какого разрешения или инструмента не хватает.
Обычному установщику нужны Git и Python 3.10 или новее. Для их установки могут
потребоваться разрешения вашей среды. APM необязателен. Нативная установка на
Windows в этой версии не поддерживается.

Если папка уже существует или установленные файлы изменены, попросите показать
конфликт и помочь сохранить ваши правки. Для обновления и удаления используйте
тот же способ, которым устанавливали навык. Не поручайте агенту принудительно
перезаписывать файлы.

## Обновление прервалось

Попросите агента изучить ошибку и выполнить восстановление по
[INSTALL.md, на английском для агента](../INSTALL.md). Эта процедура относится
к собственному установщику. У APM свои служебные файлы, и порядок восстановления
может отличаться. Сохраните сообщение об ошибке и локальные правки до проверки.

## Переход со старой ручной установки

В инструкции версии 0.1.0 нужно было копировать несколько отдельных навыков
и вызывать `$ceo` или `/ceo`. Начиная с 0.2.0 устанавливается один самостоятельный
навык `ceo-ai`. Новый установщик не может определить, кому принадлежат старые
вручную скопированные файлы.

Попросите агента найти старую копию, сравнить её с исходной версией и выделить
ваши изменения. Сначала разберите, какие старые файлы можно сохранить в резервной
копии и удалить, затем разрешите эту очистку. После этого установите `ceo-ai`
в проект и вызывайте по новому имени. Сохраните остальные навыки и настройки.

## Получить помощь

[Создайте issue](https://github.com/bearatol/ceo-ai/issues/new/choose): укажите
приложение и его версию, операционную систему, версию CEO AI, способ установки
и точный текст ошибки. Опишите ожидаемый и фактический результат. Удалите из
примеров закрытые материалы проекта, промпты, ключи доступа и личные пути.

О возможной уязвимости сообщите по [приватному каналу, инструкция на английском](../SECURITY.md).
Для исправлений и переводов есть [правила участия, на английском](../CONTRIBUTING.md).
